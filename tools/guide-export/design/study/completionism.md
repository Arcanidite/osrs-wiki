# Lady Aeris - Completionism Guide

## Structure

### Section/Phase Hierarchy
The guide presents TWO divergent paths, rather than a unified continuum:
1. **SKILLS** (two subsections)
   - Maxing: All 23 skills to 99
   - Quest Cape: Variable requirements (50–75 per skill)
2. **GEAR PROGRESSION** (four stages)
   - Starting phase
   - Mid-game phase
   - Late-game phase
   - End-game phase

No explicit narrative phases (e.g., "early game," "mid-game") or checkpoint concepts (e.g., episodes, region gates, diary tiers) are defined. No overarching quest chain sequencing or activity ordering is provided.

## Task Grammar

Not demonstrated in this guide. Individual tasks are stated as skill-level checkpoints only; no example task shows interleaving, prep sequence, or how activities batch together.

Example requisites extracted (not as tasks, but as raw requirements):
- Reach 99 Defence for maxing path
- Reach 65 Defence for quest cape access
- Obtain mid-game phase gear before late-game content
- Reach 75 Magic (quest cape) or 99 Magic (maxing)

## Interleaving & Prep Wisdom

**NOT ADDRESSED.** The guide is purely a checklist of levels and gear stages. It does NOT explain:
- How skills interleave with quest chains
- Which activities run in background (e.g., farm runs, GotR, birdhouse loops) on a cadence
- What supplies are prepared ahead-of-time vs. just-in-time
- "Do X while Y" patterns
- Where to break (train-to-breakpoint-then-move rules)
- Activity batching or optimal ordering
- Passive or concurrent activity management

This is a **critical gap** for a completionism guide; real progression wisdom lies in knowing when to pause training, gather resources, and re-engage with a rested skill.

## Self-Sufficiency / Gathering

**NOT ADDRESSED.** The guide does not discuss:
- How consumables (food, potions, runes, ammo) are sourced (gathered vs. produced vs. bought)
- Whether any gear is crafted or gathered
- Group-gathered activities
- Supply chain strategy for self-sustenance

Completionism historically values DOING the gathering (skilling out the relevant stats) rather than Grand Exchange shortcuts; this guide provides no such guidance.

## Steer-Point Orientation

The guide recognizes only TWO steer-point types:
1. **Levels**: 
   - Maxing path: All 23 skills to 99
   - Quest Cape path: Variable thresholds per skill (50–75)
2. **Gear tiers**: Progression through four equipment stages (Starting → Mid → Late → End)

**Missing steer points:**
- Quest checkpoints (no quest chain sequencing)
- Unlock/access gates (e.g., diary tiers, region access, minigame unlocks)
- Collection log milestones or item collection targets
- Skill breakpoints beyond target levels (e.g., unlocks at 52, 61, 72 Agility)
- Group activity access gates (e.g., COX availability, ToB requirements)
- Activity-specific pacing (e.g., "farm runs active for weeks; pause here to consolidate supply")

## Summary

Lady Aeris - Completionism Guide is a **structural framework** with minimal operational content. It defines TWO skill paths (maxing vs. quest cape) and FOUR gear stages, but does NOT provide the interleaving, prep, or self-sufficiency wisdom that makes a completionism guide actionable. Downstream reasoning agents will need to unwind nearly every coarse item and invent the sequencing logic independently.
