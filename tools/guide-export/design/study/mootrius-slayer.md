# Mootrius Ironman Slayer Guide — Structure & Requisites

## Phase Hierarchy

1. **Pre-Slayer Preparation** (entry: none)
   - Acquire base melee/ranged/magic gear to ~60 combat stats
   - Enables: Starting slayer tasks with progression

2. **Turael Skipping** (entry: any level; persistent throughout)
   - Block 7 unwanted low-level tasks (wolves, cave crawlers, crawling hands, lizards, banshees, skeletons, ghosts)
   - Cycle via Turael to target specific monsters for resources
   - Enables: Task curation without point waste

3. **Mazchna Point Grinding** (entry: 20 combat; levels 20–75+)
   - Run 1st–9th Mazchna tasks + 10th Konar for optimal point yield
   - Block: killerwatts, mogres, shades, ice warriors, catablepon, cockatrice, vampyres
   - Objective: Unlock Bigger/Badder, Slayer Helmet, Ring Bling in priority order
   - Enables: Access to superior monsters, efficient gear/supplies, slayer ring crafting

4. **Nieve Experience Phase** (entry: 85 combat)
   - Turael-skip undesirables; cycle Nieve for rapid XP on chosen task types
   - Leverages Bigger/Badder + Slayer Helmet for efficient monster hunting
   - Blocks emphasize speed over points; leverages dust devils, nechryael, abyssal demons
   - Enables: Leveling into Duradel range

5. **Duradel Profitability** (entry: 100 combat)
   - Turael-skip; get tasks from Duradel; focus high-value drops + boss assignments
   - Unlock Boss Slayer for Konar/Duradel/Nieve boss tasks
   - Extends include dragon/metal dragon for rare drops
   - Enables: Sustained gear progression via slayer drops; endgame finality

## Task Grammar

A **slayer task** = { slayer master | skip target } + { monster type } + { goal: XP | points | drops | supplies } + { interleaving: quest/diary/farm/supply run ahead-of-time }

Example tasks (≤12 words each):
1. Block wolves Turael; cycle to target cows for hide.
2. Nine Mazchna tasks, tenth Konar, bank for slayer points.
3. Dust devils at 65+ slayer; AFK splashing, collect rune drops.
4. Bigger/Badder: superiors on Nieve tasks yield rare gear.
5. Boss slayer Duradel; instances enable drops without multi-competition.
6. Ring Bling crafting 75: slayer ring teleport infrastructure mid-game.

## Interleaving & Prep Wisdom

### Continuous Background Activity
- **Farm/Birdhouse Runs**: Scheduled between task banking intervals (herb collection feeds herblore potions; seeds enable farming progression).
- **Supply Runs (JIT)**: Teleport tablets from Construction; bracelets from Crafting; ammunition from drops/crafting.
- **Herb Bundling**: Collect drop herbs during slayer; dry/grind JIT for pots.

### Sequential Gating by Skill/Quest
- **Fairytale I → Dramen staff** (then fairy ring fast teleports to task zones).
- **Client of Kourend → Teleport access** to Kourend tasks (before Mazchna phase).
- **Crafting 27 → Expeditious bracelet** (critical for task speed; worn during Turael skipping).
- **Crafting 55 → Slayer helmet** (after Malevolent Masquerade unlock; massive damage/speed boost).
- **Crafting 75 + Ring Bling unlock → Slayer ring** (enables mid-phase lodestone teleportation).

### Batching Patterns
- **Turael Skip Loop**: 1st–9th tasks with Mazchna (points), 10th reset via Turael (no loss; repositions at point-yielding master).
- **Bigger/Badder Phase**: Once unlocked, shift ALL tasks to superior-bearing runs for rarer drops and XP bonus.
- **Boss Extensions**: Only after 100+ combat + Boss Slayer unlock; instances prevent multi-competition but require supplies & progression.

### "Do X While Y" Rules
- **Train to combat breakpoint (20/85/100), then pivot**:
  - 20 → Mazchna phase (rapid point accumulation).
  - 85 → Switch to Nieve (XP-optimal; use unlocks from phase 3).
  - 100 → Switch to Duradel (profit-optimal; boss tasks for rares).
- **Interleave quests during supply drought**: Fairytale I, Client of Kourend, Monkey Madness II unlock fast travel; do between task banking windows.
- **Supplies run parallel**: Herbs drop during slayer; process (dry/grind) JIT; construct teleport tablets during Turael downtime.

### Coarse Optimization Wisdom
- **Blocklist tuning**: Early game prioritizes speed (fewer monsters wasted on bad tasks); late game balances points for boss unlocks.
- **Gear progression**: Free-to-play base (Helm of Neitiznot, Dragon scimitar, Dragon defender) → Slayer drop rewards (Superior combat gear, 10% drop rate from superiors) → Endgame extensions (boss drops, rare gear).
- **Teleport infrastructure first**: Expeditious bracelet (27 Crafting) + Fairy Ring (Fairytale I) = fastest early task cycling; Slayer Ring (75 Crafting, 150 pts) replaces at mid-tier.

## Self-Sufficiency & Gathering

### Consumables (Non-Purchased)
- **Food**: Killed during slayer (cows, chicken, fish/shrimp from low-level tasks); cooked with Cooking gained on-task.
- **Potions**: Herbs collected as slayer drops; ground/brewed via Herblore after collection. Requires no external supply.
- **Runes/Ammo**: Drop acquisition during slayer; stackable ammo (arrows, bolts, runes) replenished from task monster loot.

### Gear Acquisition
- **Base gear (60–85 combat range)**: Looted from early slayer tasks (hide armor, leather, daggers, crossbows).
- **Slayer helmet (55 Crafting, 400 pts)**: Crafted from Malevolent Masquerade unlock; no external materials.
- **Slayer ring (75 Crafting, 150 pts + ring materials from drops)**: Crafted; enables mid-phase fast travel.
- **Superior monster gear**: Dropped at 10% rate when Bigger/Badder active; yields rare/higher-tier drops (e.g., enhanced weapon drops, armor upgrades).

### Teleport Infrastructure
- **Dramen staff (Fairytale I quest reward)**: Fairy ring access without payment.
- **Kourend teleports (Client of Kourend quest reward)**: Fast access to Kourend tasks.
- **Teleport tablets (Construction, level 17 Magic + 38 Crafting + 38 Mining)**: Created via Sawmill, Draynor Manor constructs; enables on-task teleport returns to base without sprint.
- **Slayer ring charges (Crafting 75 + materials)**: Reusable slayer teleports; charges not consumed until late endgame.

### Group Gathering Notes
- **None explicit**: This is primarily solo progression; group content (e.g., Slayer Dungeons) is optional optimization, not required.

## Steer-Point Orientation

### Level Milestones
- **20 Combat**: Mazchna unlocked; entry to point grinding phase.
- **55 Crafting**: Slayer helmet craftable; massive efficiency boost.
- **65+ Slayer**: Dust Devil / Basilisk access; task type diversity spike.
- **75 Crafting**: Slayer ring craftable; mid-phase teleport infrastructure complete.
- **80+ Slayer**: Nechryael, Abyssal Demon access.
- **85 Combat**: Nieve unlocked; shift to XP-optimal phase.
- **100 Combat**: Duradel unlocked; shift to profit-optimal phase.

### Non-Level Steer Points (Unlock/Gear/Access)
- **Bigger and Badder (50 pts)**: Superior monster spawns; 10% rarer drops. CRITICAL early unlock.
- **Malevolent Masquerade (400 pts)**: Slayer helmet crafting gate. CRITICAL mid-phase.
- **Ring Bling (150 pts)**: Slayer ring crafting gate. Enables fast travel infrastructure.
- **Task type unlocks** (Dust Devils, Nechryael, Abyssal Demons, Hot Stuff/TzHaar): Enable strategic task selection for XP/points balance.
- **Boss Slayer (200 pts)**: Gate for Duradel/Konar boss assignments; enables high-value drop farming.
- **Fairy Ring Access (Fairytale I + Dramen staff)**: Fast task cycling early game; persistent resource.
- **Kourend Teleport Access (Client of Kourend)**: Enables Kourend-based task efficiency; persistent resource.

### Collection Log / Activity Milestones
- **Slayer Helmet Acquisition**: Marks phase transition (post-Mazchna point grind).
- **First Superior Monster Kill**: Marks Bigger/Badder unlock validation; rare drop acquisition begins.
- **Blocklist Completeness**: Marks Turael skip optimization; task curation locked in.
- **Construction Teleport Tablets**: Marks supply chain independence; no GE reliance for mobility.
