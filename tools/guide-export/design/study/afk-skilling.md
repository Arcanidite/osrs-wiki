# AFK Skilling Methods — Structure & Requisites

## Phase Hierarchy

The guide organizes methods by skill category, then by method within each skill. No linear progression is encoded; each method is independently viable at its stated level.

### Skill Categories
1. **Non-Combat Skills** — Woodcutting, Mining, Cooking, Fishing, Magic, Prayer
2. **Combat Skills** — Attack, Strength, Defence, Ranged, Magic, Hitpoints, Slayer

### Method Tiers per Skill

Each skill lists methods ordered by AFK window duration (typically 1–30 min). Within a skill, methods scale with level and gear; no explicit episode/checkpoint structure.

## Task Grammar

### Format
A task is: Train [skill] via [method] for [duration] with [equipment/supplies], yielding [XP rate].

### Paraphrased Examples (≤12 words)
1. "Autocast enchanting jewelry; 1:53 AFK window; 63,180 XP/hour (Magic)."
2. "Cook anglerfish; 1:07 AFK; 310,000 XP/hour (requires 84 Cooking)."
3. "Chop infected roots; 30:00 AFK; 9,100 XP/hour (requires 65+ Woodcutting)."
4. "Afk splashing ice spell; 20:00 AFK; 60,600 XP/hour (requires magic gear)."
5. "Sand crabs melee training; 10:00 AFK; 100,000 XP/hour (requires 10+ Attack)."
6. "Plank make auto-cast; 1:30 AFK; magic XP (requires runes + logs)."

## Interleaving & Prep Wisdom

### Limitations of This Guide

**This is a reference catalog, not a sequenced progression plan.** It lists standalone methods with no explicit interleaving, batching, or "do X while Y" guidance. It does NOT describe:
- Quest prerequisites that unlock methods
- Diary requirements gating gear/rewards
- Gathering vs. buying trade-offs
- Background tasks (farm runs, birdhouse rotations, supply prep)
- Training-to-breakpoint rules
- Skill ordering constraints

### Key Implicit Patterns

1. **Afk windows are hard limits** — methods capped at 30 min (logout threshold). Longer training requires multi-session planning, not encoded here.

2. **Combat methods benefit from combat task rotations** — melee (crabs/NMZ) + ranged (NMZ/chinning) + magic (splashing/barrage) can run on separate accounts/schedules, but guide does not sequence these.

3. **Leveling gates methods** — low-level methods (crabs at 10 Attack) precede mid-tier (NMZ at 40+); guide lists thresholds but does not prescribe when to pivot.

4. **Optimal equipment implicit** — rates assume best-in-slot or near-BiS gear; actual yields drop significantly with lesser gear. NO guidance on obtaining or crafting that gear.

5. **Supplies assumed available** — Anglerfish, runes (for plank make), barrage spells, etc. are listed ingredients but NOT sourced (GE assumed; this violates self-sufficiency).

### Missing Wisdom for Interleaved Progression

- When to unlock Lunar/Ancient spellbook for methods
- How to batch cooking/crating while fishing
- Slayer quest/assignment interactions with combat AFK
- Gear tiers (rune → barrows → torso → BiS)
- Farming/harvesting cadence for supplies (herbs for potions, logs for Firemaking)
- Which unlocks (e.g. songbird unlocking fishing spots) gate which methods

## Self-Sufficiency / Gathering

### What the Guide Assumes Available

- **Runes** (e.g. Air for plank make) — no gathering method specified
- **Food** (Anglerfish, etc.) — implicitly bought or fished
- **Logs** (for Plank Make) — no explicit source
- **Combat gear** (Trident, Staff, BiS armour) — no crafting path given
- **Potions** (for NMZ) — no brewing instructions

### What Guide Excludes

The guide explicitly does NOT cover:
- Gathering or producing consumables
- Crafting gear from raw materials
- Skilling synergies for self-sufficiency
- Group activities (raids, PvM for drops)

### Implication

This guide is designed for **mid-progression players who already have supplies stocked**, not for early-game burndown or self-sustaining progressions. To retrofit this into a self-sufficient model, a downstream agent must:
1. Map each method's ingredient (rune, food, log, gear)
2. Trace to gathering/production activities (Runecrafting, Fishing, Woodcutting, Crafting, Smithing)
3. Sequence those activities AHEAD or JIT before the AFK method

## Steer-Point Orientation

### Milestones Encoded

1. **Skill levels** — Each method has a minimum level requirement (10 Attack, 30 Woodcutting, 84 Cooking, etc.)
2. **Gear tiers** — Implicit progression from early-game equipment to "optimal skilling equipment" (BiS)
3. **AFK window efficiency** — Methods ranked by XP/hour; longer windows → slower rates (1:07 Anglerfish at 310k/h vs 30:00 Infected Roots at 9.1k/h)

### Steer Points NOT Encoded

- **Quest gates** — No method notes which quests unlock it (e.g., Lunar Diploma for plank make)
- **Diary gates** — Wildy Diaries unlock Straglewood; Desert Diaries unlock other methods; no routing
- **Access gates** — Which regions/banks/NPCs must be unlocked first
- **Unlock milestones** — E.g., "unlock Lunar spellbook, THEN plank make becomes available"

### Progression Pitfall

A player following this guide in order of AFK efficiency (fastest methods first) will likely:
1. Reach gating content (diary walls, quest walls, region access)
2. Have no fallback or branching guidance
3. Get stuck or forced to buy supplies instead of gathering

### Dominant Steer Point

**AFK Efficiency Ratio** — methods are implicitly ordered by XP/hour within each skill. The guide's mental model is: "maximize AFK XP gain per unit time." This suits stockpiled-gear players but conflicts with self-sufficient progression (which requires prep/gathering time).

## Unknowns Flagged for Unwinding

- **Quest chains gating methods** — which quests unlock Lunar, Ancient, which dungeons (NMZ, Slayer tower)
- **Diary routing** — which diaries unlock which methods or improve rates
- **Gear branching** — early/mid/endgame gear for each method
- **Supply loops** — how to farm, fish, gather ingredients in background
- **Slayer synergy** — which Slayer tasks can be done AFK, which unlock new methods
