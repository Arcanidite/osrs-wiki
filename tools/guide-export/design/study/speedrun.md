# Speedrunning Guide — Structure & Interleaving

## Section/Phase Hierarchy

Four primary **speedrun categories** on F2P Ironman progression axis:

1. **Tutorial Island%** — Entry gateway (very short)
   - Objective: Complete Tutorial Island → arrive at Lumbridge
   - Foundational for all other runs
   - No external requirements

2. **F2P Black Knights' Fortress Ironman%** — Early quest milestone
   - Objective: Accumulate 12 Quest Points → complete Black Knights' Fortress quest
   - Intermediate checkpoint
   - Ironman + F2P constraint

3. **F2P Champions' Guild Ironman%** — Quest progression milestone
   - Objective: Accumulate 32 Quest Points → enter Champions' Guild
   - "Most active run category"
   - Showcases early F2P questing chain
   - Ironman + F2P constraint

4. **Obtain Camo Top%** — RNG-dependent random event
   - Objective: Trigger & complete Drill Demon random event → receive Camo top
   - Duration: 5 minutes to 88+ days (extreme RNG variance)
   - Verification: Full video OR screenshot with Hans age confirmation

**Checkpoint hierarchy:** Tutorial Island → 12 QP → 32 QP, with RNG category as orthogonal variance.

## Task Grammar

**Core task unit**: Quest completion → Quest Points earned, enabling next quest.

**Example tasks (≤12 words):**
1. Complete quest chain targeting specific quest point thresholds.
2. Bank cycle: deposit load, withdraw quest items, proceed.
3. Travel optimized: hold spacebar through dialogue, use numpad.
4. Weight management: stockpile run energy during heavy load.
5. Checkpoint: deathwarp intentionally if routing requires reset.
6. Wait random event trigger for Drill Demon appearance.

**Notation shorthand:**
- `[BANK]` = deposit worn + inventory, withdraw quest items
- `[Split]` = checkpoint location for timing verification
- `[Deathwarp]` = intentional enemy-caused death for routing benefit
- `(1)/(2)/(3)` = NPC dialogue option selection
- Quest abbreviations: RM, RG, PT, WP, VS, RJ, DS, PAR, CA, ETC, BKF, GD, XMS

## Interleaving & Prep Wisdom

**Timing governance:**
- RTA (Real-Time Attack) timing only — no turn-based pausing
- Mouse cursor must remain visible throughout
- No Skippy or custom RuneLite plugins
- Multilogging permitted if documented

**Concurrent activity patterns:**
- Weight management runs DURING travel: "Stockpile run energy while carrying heavy load, run when light."
- Dialogue advancement happens while moving: "Hold spacebar through all dialogue. Click doors and be walking."
- Banking cycles interleave quest progression: queue next quest items while depositing current load.

**Adaptive routing philosophy:**
- "Huge number of backup strats available"
- "No mistakes, only happy little accidents" — indicates on-the-fly route pivots based on spawn RNG, drops, or NPC positioning

**Quest chain interleaving:**
- Early F2P quests form chains unlocking later quests
- Quest Points accumulate across multiple quests (not depth per quest)
- 32 QP milestone (Champions' Guild category) showcases most early F2P content in optimal order

**Just-in-time patterns:**
- Items for current quest obtained immediately before quest start
- No bulk gathering observed — run uses fresh item drops/crafting per quest

## Steer-Point Orientation

**Primary steer points:**
1. **Tutorial Island completion** — binary gate, required by all runs
2. **Quest Points (accumulation)** — primary progression metric
   - 12 QP checkpoint: Black Knights' Fortress category
   - 32 QP checkpoint: Champions' Guild category (phase milestone)
3. **Category selection** — determines quest sequence order
4. **RNG events** — Drill Demon spawn (Camo Top%), NPC drops, quest item availability
5. **Checkpoint times** — standard splits at quest completion, entrance messages

**Non-level, non-quest steer points:**
- Ironman account creation/maintenance (access gate)
- F2P worlds availability (access gate for Ironman variants)
- Random event trigger probability (Camo Top% category)
- Equipment updates implicitly tied to quest rewards (not detailed here)
