## A. COMBAT
- **Attack/Strength/Defence (Melee — one wiki page):** 1-50 combat-xp quests (+MM1 reward on
  Att/Def) → 50-65/65/60 0-time sand crabs (60 Att first for d scim) → 65-80/85/80 Dragon
  defender + 0-time NMZ → 80-99 BXP from Slayer OR 0-time NMZ.
- **Ranged:** 1-85 cannon BXP from Slayer → 85-99 chinning MM2 tunnels w/ Rigour. (daily ecto
  from Morytania Elite for bonecrusher charges; full void/Ava's not needed just for max.)
- **Magic:** 1-17 Imp Catcher/Witch's Potion/Grand Tree → 17-55 MTA (Bones-to-Peaches ~127k)
  + Fire Strike while questing/running (low-alch @21, telegrab @33, enchant @…) → 55-90
  alch/Magic Imbue while questing+skilling → 90-99 BXP from Slayer.
- **Prayer:** 1-70/96 Hydra/Dragon bones on Gilded/Chaos altar → 70-96 superior bones on
  Chaos altar → 96-99 BXP from ash sanctifier + bonecrusher during Slayer/chinning.
- **Hitpoints:** 10-24 Witch's House → 24-99 BXP from combat/Slayer.
- **Slayer:** 1-50 Wildy Slayer (viggora/craws + cannon; block Fire giant/Black demon/
  Hellhound; to ~1000 pts) → 4-9 Turael tasks → 50-99 Duradel (100 cb). Point-spend order:
  block greaters, unlock bloodveld/TzHaar/superiors; block Wyrms@62, "stop the wyvern"@66,
  6th block via Lumbridge Elite@75 (quest-cape req), block Gargoyle@75, extend Nechryael@80,
  unblock Fire giant + block Drakes@84, extend Abyssal@85, unblock Black demon + block Cave
  Kraken@87. Burst/barrage on defensive; Ice Barrage @90 (imbued heart+preserve), Smoke @83
  boost; wild-pie boost 80→85 (Mory Elite) / 90→95 (K&K Elite) for full bonecrusher prayer xp.

  HS floors 1-2 → 72-82 1-3 → 82-92 1-4 → 92-99 1-5 (graceful from Ardougne@91, summer pies +
  preserve). *Rooftop path* — 1-60 quests/lamps + barb-fish BXP → 60-80 Seers (Hard Kandarin)

  rooms 7-8 OR Ardy knights → (49-99 artifacts, can multiskill FM after Zeah house quests).

## C. ARTISAN
- **Fletching:** 1-99 multiskill arrows/darts during other skills (Sepulchre best).
- **Herblore:** 3-99 best potion for level, watch gp/xp.
- **Crafting:** 1-34 quests+cut gems → 34-63 cut rubies → 63-66 green d'hide bodies → 66-71/99
  air battlestaves → 71-99 blue/red/black d'hide. (61 craft + 74 magic → Superglass Make 18:3
  no-pickup, blow highest item — the FAQ crafting answer.)
- **Smithing:** 1-40 quests → 40-85/98 gold ore @ Blast Furnace (gold ore 225gp ea, any qty)
  → 85-88 Giants' Foundry (outfit) → 88-98 addy platebodies → 98-99 BXP infernal pickaxe @
  granite.
- **Construction:** 1-16 best wooden furniture → 16-33 crafting table 1 → 33-52 oak larders →
  52-77/99 mahogany tables → 77-99 mahogany/gnome benches. (demon butler @50.)
- **Runecraft:** *(solo/1-runner)* 1-39 quests → 39-81/83 combo runes best 2 pouches → 81/83-85
  GotR for Colossal Pouch (~500k rc xp drop; +500k for outfit; 180 games) → 85-99 combo runes
  w/ Colossal. *(4 runners)* 39-99 lava runes. PREREQ: Magic Imbue castable (82 Magic + Arceuus)
  before starting. Combo runes strong post-update (GotR magic 82).
- **Firemaking:** 1-30 normal logs + charged Gnomish firelighter → 30-85 best logs for level →
  85-90 BXP infernal axe @ teaks → 90-99 redwood logs. (stop failing ~45 FM → multiskill during
  artifact thieving.)
- **Cooking:** 1-18 (see wiki) → 18-30 1t poison karambwans → 30-70/98/99 Tai Bwo Wannai Trio +
  1t karambwans → 70-99 wines → 98-99 BXP cut-eat barb fishing. (cooking gauntlets don't help
  karambwans; Hosidius range does.)

## D. GATHERING
- **Woodcutting:** 1-27 quests (Monk's Friend/Icthlarin/Eyes of Glouphrie/Enlightened Journey)
  → 27-35 oaks → 35-99 1.5t teaks Fossil Island (infernal axe @61 needs 85 FM).
- **Fishing:** *(drift net, saves ~50h)* 1-31 quests (Sea Slug/Fishing Contest/Tai Bwo/RFD
  Pirate Pete) → 31-47 3t fly → 47-96 drift net (99 Hunter here → 96 Fishing) → 96-99 cut-eat
  barb (want 98 Cooking). *(no drift net)* 31-45 Fishing Trawler (Angler) → 45-58 3t fly →
  58-99 cut-eat barb.
- **Mining:** 1-33 quests (Digsite/Doric's/Plague City) → 33-45 3t iron / superheat-iron+drop →
  45-85/99 3t granite (85 smith → infernal pickaxe) → 85-99 Volcanic Mine (crystal pickaxe).
  (Varrock body 2 asap; Circlet of Water if <99 hp.)
- **Hunter:** 1-9 museum quiz → 9-44/80/99 best birdhouses → 44-99 drift net (47 Fishing) →
  80-99 red/black chinchompas.
- **Farming:** 1-33 all quests → 33-99 best tree+fruit trees + hardwood/special trees.
  (ultracompost+iasor for magic/dragon fruit; ≥1 run/day finishes before max; Kronos-seed set
  = palms/mahogany/calquat/celastrus/redwood/hespori.)

## C-BURNDOWN. Cross-skill dependency seeds (resolve so bands land in order)
- Magic Imbue (82 Magic + Arceuus) BEFORE Runecraft combo runes.
- 85 Firemaking BEFORE infernal axe (WC teaks 85-90 / general FM multiskill).
- 85 Smithing BEFORE infernal pickaxe (Mining 3t granite → Volcanic).
- Quest-cape req → Lumbridge Elite → Slayer 6th block @75.
- 47 Fishing + 99 Hunter drift-net → 96 Fishing (combined-skill payoff).
- 98 Cooking BEFORE 96-99 cut-eat barb Fishing.
- 61 Crafting + 74 Magic → Superglass Make.
- SotE completion → Prifddinas rune shops (bloods/deaths/natures/cosmics) + Prif agility.
- Diaries as XP-lamp + method-unlock gates (Hard Kandarin→Seers, Hard Rellekka→Rellekka, etc.).
- Barb-fishing gives Agility+Strength BXP (multiskill anchor for early Agility 1-60/62).
- Quests are a first-class XP source across skills — `Quest_experience_rewards` (do every quest
  you can for the reward xp); many bands OPEN with "quests + diary lamps".
