# Raging Echoes League: Varlamore First Region — Granularity Analysis

**Source:** https://oldschool.runescape.wiki/w/Guide:Raging_Echoes_League/Varlamore_First_Region
**Slug:** re-varlamore
**Guide Purpose:** Rush Varlamore region progression and Hunters' Rumours on league opening day while preparing for 99 Hunter with experience multipliers.

---

## Granularity Findings

### Overall Structure
The guide divides into **5 sequential progression parts**:
1. Tier 2 Relic & Varlamore Unlock (~760 points)
2. Early Varlamore & Tier 3 Progression (~1370 cumulative)
3. Hunter Advancement (72–75 level target)
4. Miscellaneous Useful Grinds (flexible/context-dependent)
5. Boss Content (Scurrius, Cam Torum)

### Atomic Grain Assessment
**Granularity Score: 2/5** (coarse-to-medium)

The guide operates primarily at **task/milestone level** rather than **click-by-click level**:
- Specifies skill thresholds and quest prerequisites precisely
- Provides resource quantities (exact in some cases, ranges in others: "50–100 nature runes," "28–49 bronze bars")
- Names quest prerequisites and dependencies explicitly
- Does NOT provide step-by-step click sequences, NPC dialogue trees, or coordinate-based navigation
- Contains tactical hints like "lure guard pattern" without full decomposition

### Representative Atomic Unit
**One completed skill threshold OR single quest milestone**

Examples:
- Reach Thieving 34 via cake stall luring
- Complete Death on the Isle quest
- Bank 28 bronze bars for smithing tasks
- Claim tier 2 relic unlock reward
- Catch moonlight moths at 75 Hunter

### Resource Specificity
- **Exact quantities:** 5500+ coins (post-Part 1), 15+ feather packs, 28–49 bronze bars
- **Ranges:** 50–100 nature runes (gathered from tree spirits)
- **Quest thresholds:** Precise skill levels (Thieving 34, Agility 32, Slayer 48, Hunter 20, Fishing 20, Runecraft 20, Construction 10)
- **No stated:** rates per hour, exact hunt counts, exact NPC positions

### Task Notation
The guide uses a marking system:
- **e.** = non-optional easy task
- **m.** = non-optional medium task
- **e?** = optional easy task (skip if contested)
- This notation aids filtering but does not provide finer decomposition

### Strategic Sequences (Partially Atomized)
Some instructions hint at multi-step sequences but remain coarse:
- "Complete Draynor Agility while alching" → implies simultaneous two-skill training but no step count
- "Lure guard pattern" at cake stall → tactic named, method not detailed
- "Build Fossil Island museum camp" → end goal stated, construction sequence omitted
- "Rush thieving to 34" → target clear, exact click sequences not provided

1. Navigate to Civitas illa Fortis cake stall
2. Execute lure-guard attack pattern
3. Steal cakes repeatedly
4. Check Thieving level periodically
5. Stop at level 34

**Decomposes into:**
1. Complete expert rumours milestone at 72 Hunter
2. Train remaining 3 levels via alternative catching methods
3. Acquire butterfly net equipment
4. Locate moonlight moth spawn area
5. Begin catching rotation

## Efficiency Annotations

- **Parallelization:** "Draynor Agility while alching" combines two skill trains during single activity block
- **Gating:** Tier 2 relic unlock (8x multiplier) gates Part 2 progression
- **Resource pre-positioning:** Bank bronze bars and nature runes before usage to avoid mid-task item searching
- **Contested task fallback:** e? tasks allow skipping if hotspot crowded
- **Quest dependency chain:** Death on the Isle requires Thieving 34 + Agility 32, gates Part 2 unlocks

## Summary

The **Raging Echoes League: Varlamore First Region** guide operates at a **coarse-to-medium granularity**. It does not prescribe atomic click sequences but rather establishes:
- Skill level thresholds (atomic targets)
- Quest prerequisites and dependencies (structural gates)
- Resource quantities and banking checkpoints (acquisition milestones)
- High-level tactical sequences (named without full decomposition)

This grain suits a **progression planner** that must unwind coarse "reach 34 Thieving" into catchable steps, and a **task router** that must schedule skill trains and quests in optimal order—but would require further downstream atomization for a click-by-click playable guide.

The guide assumes player familiarity with location navigation, NPC dialogue, and basic game mechanics, leaving those atomic substeps to player knowledge or supplementary reference guides.
