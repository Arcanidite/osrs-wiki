What this is

The world and its collision are decoded from the real game cache (OpenRS2 archive, cache 2499 · build 236 · 2026-03-18) by tools/openrs2_extract.py: terrain block flags, wall edges and corners, and object footprints honoring each object's clip type — the same static clipping rules the game applies. Movement is tick-true: one game tick every 600 ms, 1 tile/tick walking, 2 running; click-to-walk uses the game-style breadth-first search with no corner cutting (source: OSRS Wiki, “Game tick” / “Pathfinding”). Press C to see the collision overlay.

Objects are live: every interactable object placement (57,130 across the world) is decoded from the cache with its real right-click menu — hover shows the game-style “default action Name” text, right-click opens the option list exactly as the cache defines it, and clicking walks you there. Doors and gates genuinely open: opening clears exactly the wall edges their closed state clips, so buildings are navigable — the same passage semantics as the game. Other actions walk you to the object and report that their effect isn't simulated yet; nothing is faked.

Still missing, and exactly why

  • NPCs in the world — NPC spawn points are not part of the cache (they are server-side data); rendering NPCs needs a separately sourced spawn dataset. (BACKLOG [client:locations-spawns])
  • Upper floors — the client renders plane 0; staircases/ladders list their real actions but plane changes aren't simulated yet.
  • The simulation — combat, quests, drops and AI run on Jagex servers and are not present in any client data; they can only be re-implemented from sourced formulas under the KB no-fabrication protocol. (BACKLOG [client:simulation])
